# Study Environment Checklist

## Physical Setup
- [ ] Laptop di flat surface (desk/table)
- [ ] Monitor jika ada (easier untuk read logs)
- [ ] Keyboard + mouse comfortable
- [ ] Chair that supports back
- [ ] Good lighting (no glare di screen)
- [ ] Temperature comfortable (not too hot/cold)

## Digital Setup
- [ ] CachyOS + Hyprland running smooth
- [ ] Terminal opens quickly
- [ ] Text editor (nano) accessible
- [ ] Wireshark installed dan tested
- [ ] Internet connection stable
- [ ] GitHub access working

## Distraction Management
- [ ] Discord/Telegram notifications MUTED
- [ ] Phone di silent mode (or another room)
- [ ] Gaming console/device turned OFF
- [ ] Browser extensions minimal (no Reddit/YouTube autoplay)
- [ ] Only 1 monitor if possible (reduces distraction)

## Supplies
- [ ] Water bottle filled ✅
- [ ] Snacks available (nuts, fruit, etc)
- [ ] Headphones charged (untuk YouTube videos)
- [ ] Pen + paper (for notes/diagrams)
- [ ] Timer or clock visible

## Pre-Session Ritual
Before setiap sesi, lakukan:
1. Make sure semua tools working (terminal, wireshark, git)
2. Close unnecessary apps
3. Set timer untuk session
4. Drink water
5. Clear mind (take 5 deep breaths)

## Post-Session Ritual
After setiap sesi:
1. Screenshot if needed
2. git add + commit
3. git push
4. Close terminal properly
5. Stretch/walk (5 min)
6. Log progress di daily_tracker.txt
